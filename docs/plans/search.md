## Pain

When downloading a new track/album, one has to:

- go to youtube.com
- search and click on video
- dodge annoying ads
- copy URL
- go to the downloader page and fill in URL, author, album, etc...

## Dream

Embed yt search in downloader page. One can choose whether insert directly the URL and other info OR search something generic in a search-bar, pick among the search results (thumbnail + metadata) and keep going with the rest of the process (mostly the tracks selection in case of palylists)

## Constraints

- no API key required. This must be as low-key as possible, we do not want to be banned for improper use
