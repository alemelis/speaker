## Pain points

- Playlists can contain tracks that I do not want to download
- Download logs are too noisy

## What I want

- When fetching a playlist, before downloading, show the full list of tracks. Allow the user to select wanted tracks with checkboxes (by default all selected). Download only selected and fix track number in metadata accordingly
- Instead of logs, show a progress bar when downloading a playlist. When downloading a single track, show a spinning wheel.
- Keep logs in the background, show them only in case of error.
